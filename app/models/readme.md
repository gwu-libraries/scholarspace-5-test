# Models

We have four types of models in use:

- ETD
  - An 'electronic thesis/dissertation' - this model has fields for ETD advisors, GW units, committee members, specific degrees. 
- JournalIssue
  - An issue of a journal, which may be made up of multiple pieces but is deposited as one document.
- AcademicDocument
  - A model for any non-ETD academic works. These could be undergraduate works from research competitions, or anything else that Scholarly Communications opts to deposit that explicitly not an ETD and not an archival document.  
- ArchivalDocument
  - Used by Special Collections, indicates that the work is not "scholarly" and is instead an archival document, such as a digitized document.
